## 🚀 Installation sur O2Switch

1. **Télécharger** le ZIP complet
2. **Dézipper** sur votre ordinateur
3. **Connexion FTP** à O2Switch (FileZilla recommandé)
4. **Uploader** tous les fichiers dans `public_html`
5. **Vérifier** que le SSL (HTTPS) est actif
6. **Tester** toutes les pages

### Vérifications post-déploiement
- [ ] Toutes les pages s'affichent correctement
- [ ] Les liens internes fonctionnent
- [ ] Le chatbot Madison s'ouvre
- [ ] Le formulaire de contact fonctionne
- [ ] Les images s'affichent
- [ ] Le site est en HTTPS
